# 待办事项提醒（网页版）

一个基于 React + Vite 的网页版待办事项提醒工具：支持待办增删改查、截止时间、提醒时间、逾期标记、弹窗提醒（页面内 Toast）、可选系统通知与声音提示；数据保存在浏览器本地。

## 运行方式

在本项目目录下：

1. 安装依赖：\`npm install\`
2. 启动开发服务：\`npm run dev\`
3. 打开浏览器访问提示的地址

## 使用说明

- **提醒**：提醒功能需要页面保持打开（浏览器关闭/标签页被系统彻底挂起时无法保证提醒）。
- **系统通知**：需要点击页面里的“允许通知”，并在浏览器弹窗里授权。
- **声音提醒**：部分浏览器会要求你先与页面交互（例如点击一下页面），之后才允许播放声音。
